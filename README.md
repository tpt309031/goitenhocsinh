# Gọi tên học sinh

Trang web gọi ngẫu nhiên học sinh dành cho lớp học tiểu học.

## Tính năng

- Chọn ngẫu nhiên bằng nguồn ngẫu nhiên của trình duyệt.
- Tên học sinh xếp thành vòng tròn, xoay trước khi công bố kết quả.
- Nhạc nền và hiệu ứng âm thanh được tạo trực tiếp trên trình duyệt.
- Chỉnh sửa danh sách lớp và tự động lưu trên thiết bị.
- Lưu các bạn vừa được gọi, hỗ trợ phím cách và thiết bị di động.

Mở `index.html` để chạy trực tiếp hoặc truy cập bản GitHub Pages của dự án.
